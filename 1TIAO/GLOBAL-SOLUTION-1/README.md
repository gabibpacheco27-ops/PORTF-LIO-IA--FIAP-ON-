## 📜 Descrição

*O EducaTodos é um protótipo de reforço escolar desenvolvido para a Global Solution 2026.2 da FIAP. Voltado a estudantes do 6º ano do Ensino Fundamental ao 3º ano do Ensino Médio, oferece exercícios de Matemática, Português, Ciências e História.

A aplicação foi desenvolvida em Python e usa um modelo de Machine Learning, treinado com dados simulados, para estimar o nível do estudante e adaptar as explicações. O progresso é salvo em SQLite e pode ser consultado em um relatório individual. O projeto se alinha aos ODS 4 (Educação de Qualidade) e 10 (Redução das Desigualdades).*

## Como executar o EducaTodos

**Pré-requisito:** Python 3.11 ou superior.

Clone o repositório ou baixe e extraia o ZIP. No macOS ou Linux, abra o Terminal na pasta que contém o arquivo `requirements.txt` e execute:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m src.main_sqlite
```

O último comando abre o menu do EducaTodos. Na primeira execução, o aplicativo cria o banco SQLite em `dados/educatodos.db`. Para continuar de onde parou, abra o Terminal na mesma pasta, ative o ambiente virtual e rode novamente `python3 -m src.main_sqlite`.
